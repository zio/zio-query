Voice and tone

ZIO Query does something clever so its users can write something simple. The voice does the same: plain words, exact claims, and the code close at hand. All copy here is a proposal for the maintainers to confirm.
5.1
Voice
Precise
Say what is batched, what is pipelined and what is cached. “Two queries instead of N + 1”, not “much faster”.
Plain
Short sentences, everyday words. Explain a term like “round trip” the first time it appears.
Calm about performance
The gains are real; let numbers and examples carry them. No superlatives.
Shows the code
A short snippet beats a paragraph. Every claim links to an example that runs.
5.2
Tone by context
DocsPatient and step by step. Start from the problem (the N + 1 query), then the fix.
ErrorsWhat happened, why, and the next step. Name the data source and request.
Release notesWhat changed and who it affects, in that order. Breaking changes first.
SocialOne idea per post, one snippet or one diagram. Friendly, never hype.
5.3
Say this, not that
Say: Two database calls instead of 101.
Not: Blazing-fast data access.
Say: Requests in parallel parts of a query are batched.
Not: ZIO Query magically optimises everything.
Say: Results are cached for the life of one query.
Not: Built-in caching layer.
Say: Write it simply; ZIO Query plans the calls.
Not: Revolutionary query engine.
5.4
In practice
README INTRO
ZIO Query lets you write data access as small, readable queries and runs them efficiently. Requests that can run together are batched, repeated requests are sent once, and results are cached for the rest of the query.
ERROR MESSAGE
Data source "UserDb" returned no result for GetUser(42). Every request sent to a data source must be completed. Complete it with a value or a failure in the CompletedRequestMap.
RELEASE NOTE
[VERSION] · Data source aspects can now limit batch size. If your database caps IN clauses, set the limit once on the data source; queries need no change.
5.5
Taglines
TAGLINE · PROPOSAL
Batching, pipelining and caching for any data source
Many requests, one round trip
From N + 1 to 2.
Write simple queries. Send fewer requests.
Batched, deduplicated, cached. Automatically.
5.6
Words
Use: request, data source, query, batch, round trip, pipeline, cache, deduplicate.
Avoid: blazing, magic, revolutionary, seamless, effortless, game-changing.
Spelling: ZIO Query, two words, both capitalised. The type is ZQuery. Never “Zio Query”, “ZIO-Query” or “ZioQuery”.
5.7
Naming other libraries
ZIO Query belongs to a line of ideas that includes Haxl and Fetch. When comparing, state facts the docs already state (for example, no higher-kinded types or implicits needed) and credit prior work by name. Never disparage.
