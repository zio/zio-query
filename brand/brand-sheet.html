ZIO Query brand

The mark is a tally turned on its side. Four lines are four requests; one cobalt strike crosses them all, the way ZIO Query sends many requests to a data source as one batch. The first line, the last line and the strike draw the Z of ZIO, so the mark stands in for the Z in the name, followed by “IO Query” in Sora.

The idea in three steps
STEP 1
Four requests, four lines
Each line is one request to a data source, the way N + 1 code would send them: one at a time.
STEP 2
One strike, one batch
A tally strike groups them, as ZIO Query groups requests into a single batch and one round trip. The strike is the only colour.
STEP 3
The Z was there all along
The first line, the last line and the strike draw the Z of ZIO. Nothing was added to the tally to make it.
